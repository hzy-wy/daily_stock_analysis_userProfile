# 首页市场看板与交易风格画像

本文说明 Web 首页市场看板和持仓页交易风格画像的产品口径、数据边界与接口约定。

## 首页市场看板

首页默认进入“看板”一级工作区，即使已经存在历史报告也不会被自动选中的报告遮挡。左侧可在“看板 / 历史 / 自选 / 今日”之间切换；看板默认市场为中国 A 股，可在中国香港、美国、日本和韩国之间切换。看板将以下信息集中到同一工作区：

- 主要指数：最新点位、涨跌幅、日内高低；
- 市场宽度：上涨、下跌、平盘、涨跌停家数和成交额；
- 板块热力：行业与概念的领涨、领跌数据；
- 市场信号灯：结构分、状态、证据理由和数据质量；
- 完整复盘入口：按当前下拉框市场触发大盘复盘。

看板使用项目既有 `MarketAnalyzer` 和数据源降级链，不新增平行行情源。指数、市场宽度、行业排行和概念排行作为四个独立分块并发刷新，单次 HTTP 请求只等待统一总预算；慢分块会继续在后台执行，已经成功的分块会先返回，不再因一个数据源超时清空整个看板。同一市场同一分块只允许一个后台刷新任务，窗口聚焦、定时轮询和手动刷新也不会为同一市场叠加前端请求。

每个分块只缓存“实际取得且通过非空校验”的最近成功结果。失败或空结果不会覆盖成功缓存；在允许的陈旧期限内，页面会继续展示最近成功值，并明确标注“陈旧数据”、数据取得时间和正在后台刷新的分块。超过陈旧期限且没有可靠结果时才显示不可用。页面不会用零值、推算值或虚构数据补齐缺失维度。

页面显示的数据状态包括：`ok`（所有受支持分块为新鲜数据）、`partial`（仅部分分块成功或仍在刷新）、`stale`（所有受支持分块均有最近成功数据，但至少一个已过新鲜期）和 `unavailable`（没有可靠成功分块）。`coverage` 表示本次响应中实际存在的数据，不再把“数据源理论支持”误当成“本次已取得”。切换市场时会丢弃上一个市场的迟到响应；刷新失败会保留当前画面。页面可见时每 60 秒自动刷新，也可手动刷新。

当前市场能力并不完全对称。A 股数据源能提供市场宽度和板块排名时会完整展示；国际市场当前以主要指数为主，只有数据源实际返回对应数据时才展示宽度或板块热力，不用零值或推算结果填充空缺。因此，“部分覆盖”表示数据能力边界，不代表所有指数均不可用。

接口：

```text
GET /api/v1/stocks/market-dashboard?region=cn|hk|us|jp|kr
```

可选配置：

| 环境变量 | 默认值 | 说明 |
| --- | ---: | --- |
| `MARKET_DASHBOARD_FETCH_BUDGET_SECONDS` | `8` | 单次看板请求等待所有外部分块的总秒数；到期即返回部分结果，后台任务不会被取消 |
| `MARKET_DASHBOARD_CACHE_TTL_SECONDS` | `60` | 最近成功分块直接视为新鲜并复用的秒数；设为 `0` 表示每次都触发刷新 |
| `MARKET_DASHBOARD_STALE_TTL_SECONDS` | `604800` | 外部刷新失败时允许展示最近成功分块的最长秒数（默认 7 天，覆盖周末/长假）；页面会明确标旧 |

single-flight 状态属于当前服务进程，不跨多实例共享；进程首次访问某市场时会从最近一条结构化大盘复盘历史恢复可用分块，再按陈旧时限判断是否展示。上游接口未统一提供行情业务时间戳时，页面“更新时间”代表本服务最近成功取得或持久化该分块的时间，不代表交易所逐笔时间。

## 交易风格画像

持仓页在当前账户范围下生成随交易记录变化的行为画像。选择单账户时只使用该账户；选择全部账户时使用全部有效账户，并将当前持仓市值换算到组合展示币种后计算集中度。新增、删除或导入交易后，画像会随持仓快照一起刷新。

雷达图包含六个行为维度，分数范围为 0–100：

| 维度 | 主要证据 | 高分含义 |
| --- | --- | --- |
| 交易活跃度 | 每 30 天交易次数 | 操作更频繁 |
| 短线倾向 | 已完成与当前持仓周期的中位天数 | 持有周期更短 |
| 持仓集中度 | 当前第一大持仓权重 | 组合更集中 |
| 分批建仓 | 已有未平仓头寸时继续买入的比例 | 更常分批加仓 |
| 止盈倾向 | FIFO 匹配后盈利卖出占比 | 更常在盈利时退出 |
| 仓位一致性 | 单笔名义金额的离散程度 | 单笔规模更稳定 |

交易匹配沿用解释性 FIFO 口径，画像读取完整交易流水而非当前分页。少于 8 笔交易或观察窗口不足 14 天时状态为“形成中”；置信度同时考虑交易笔数、观察天数、涉及标的数和可匹配卖出样本。证据不足的维度显示为不可用，不用默认中位数补齐雷达图。

画像是对已记录行为的描述，不是投资能力评分、收益预测或投资建议。截图识别遗漏、历史卖出缺少对应买入、账户数据不完整、行情或汇率缺失都会降低可解释性；页面会显示样本量、置信度与限制项。

接口：

```text
GET /api/v1/portfolio/trader-profile?account_id=<id>&as_of=YYYY-MM-DD&cost_method=fifo
```
